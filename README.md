# أثر — رحمهم الله

موقع عربي مجتمعي هادئ لتخليد ذكرى المتوفين والدعاء لهم.

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد المشروع.
3. نفّذ:
   `npm install`
4. شغّل:
   `npm start`
5. افتح:
   `http://localhost:3000`

## الإدارة
الرابط:
`/admin`

لأغراض العرض المحلي فقط، بيانات الدخول الافتراضية:
- username: admin
- password: change-this-password

**غيّر كلمة المرور قبل أي نشر حقيقي.**

## الصوت
يمكن للمدير رفع 5 ملفات MP3 من لوحة الإدارة. كل تذكرة معتمدة تحصل على مقطع واحد محفوظ في قاعدة البيانات.

## ملاحظات
هذا المشروع نسخة بداية كاملة قابلة للتطوير. قبل النشر العام، اربطه بمصادقة حقيقية، HTTPS، تخزين صور/صوت Object Storage، وبيئة أسرار آمنة.
